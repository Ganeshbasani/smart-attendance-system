## ✨ Why AttendX?

Managing attendance through paper registers or scattered spreadsheets can make
tracking, reporting, and analysis unnecessarily difficult.

**AttendX** provides a centralized web-based workflow for managing student
records, recording attendance, and viewing attendance insights through an
interactive dashboard.

The project focuses on three core goals:

> **Simple attendance management → Reliable record keeping → Actionable analytics**

# 🎯 Core Features

| Feature | Description |
|---|---|
| 🔐 Authentication | Teacher registration and login workflow |
| 👨‍🎓 Student Management | Upload, validate, search, and manage student records |
| 📂 CSV Import | Load student information from CSV files |
| ✅ Attendance Tracking | Mark students as present or absent |
| 🔍 Student Search | Quickly locate students during attendance workflows |
| 📊 Analytics Dashboard | View attendance statistics and visual insights |
| 📈 Interactive Charts | Understand attendance distribution and trends |
| 📅 Attendance Reports | Review attendance across different reporting periods |
| 🎯 Attendance Grading | Generate attendance-based performance indicators |
| 💻 Responsive UI | Clean interface designed for practical classroom use |
